# sweet-crumbs-bakery
A responsive bakery landing page built with HTML, CSS, and JavaScript.

About this project:
<br>
Sweet Crumbs Bakery is a simple and responsive bakery website showcasing delicious baked goods with a clean and attractive design.

Features:
- Responsive design for desktop and mobile devices
- Bakery homepage with hero section
- About section
- Product showcase
- Interactive shopping cart 
- Quantity increase and decrease functionality
- Checkout section
- Navigation menu
- Back to Top button

Technologies Used:
- HTML5
- CSS5
- JavaScript

Live Demo:

Visit the website: [Sweet Crumbs Bakery live link] (https://sweet-crumbs-bakery-site.netlify.app/)
